Events Endpoints

Description: Returns an array of active events with registered count and available seats.

[

    "id": 1,
    "title": "CodeAlpha Tech Summit 2026",

    "category": "TECH",
    "location": "Baku Convention Center & Virtual Stream",
    "date": "2026-11-15T09:00:00Z",
    "capacity": 200,
    "organizer_name": "admin",
    "registered_count": 42,
    "available_seats": 158,
    "is_full": false
  }
]

Registration Endpoints

Request Body:

{

  "phone": "+994 50 123 45 67",
  "notes": "Looking forward to backend session!"
}
Response Example (201 Created):
{
  "message": "Registration successful! You have secured your seat.",
  "registration": {
    "id": 5,
    "ticket_code": "EVT-8A7B2C1D",
    "event": 1,
    "event_title": "CodeAlpha Tech Summit 2026",
    "full_name": "Leyla Mammadova",
    "email": "leyla@example.com",
    "status": "CONFIRMED"
  }
}

Description: Returns all active and previous registrations for the authenticated user or matching email query.

    "ticket_code": "EVT-8A7B2C1D",

    "full_name": "Leyla Mammadova",
    "email": "leyla@example.com",
    "status": "CONFIRMED"
  }
]

Description: Updates the registration status to CANCELLED, freeing up capacity for the event.

Response Example (200 OK):
{
  "message": "Registration successfully cancelled. The seat has been freed.",
  "registration": {
    "id": 5,
    "ticket_code": "EVT-8A7B2C1D",
    "status": "CANCELLED"
  }
}

Authentication Endpoints

  • POST /api/auth/register/ - Register a new attendee or organizer account
  • POST /api/auth/login/ - Log in and create user session
  • POST /api/auth/logout/ - Terminate user session
  • GET /api/auth/me/ - Check current authentication status
